# ABLE FASHION LAB
중·고등학생 4인 1조용 뷰티테크 실습 웹앱. Chrome에서 https://able0220.github.io/able-fashion-lab/ 을 엽니다.

## 수업 전 점검
1. 노트북에 USB 웹캠과 같은 색온도의 LED 두 대를 준비합니다. 두 조명을 얼굴 양쪽에 놓고 필터를 끕니다.
2. 수업 가이드의 모델 점검을 실행합니다. MediaPipe 실행 파일 및 모델 로딩에는 jsDelivr와 storage.googleapis.com 접속이 필요합니다.
3. 카메라 시작 → Chrome 카메라 허용 → 장치 목록에서 USB 웹캠 선택. 다른 프로그램이 카메라를 사용 중이면 종료합니다.
4. 한 명만 정면을 보게 하고, 얼굴 윤곽과 세 측정 위치를 확인합니다. 측정 준비 완료가 뜨면 현재 얼굴 측정을 누릅니다. 각 학생의 피부를 정확히 재현하려면 보정 장비가 필요합니다.
5. 드레이핑에서 A를 고정하고 다른 색을 선택해 좌우를 비교합니다. 선호색을 담고 계절을 직접 선택합니다. 헤어에서 디자인과 염색을 별도로 비교합니다.
6. 패션 스타일링에서 가상 체형과 의상을 바꿉니다. 코디 A를 저장한 뒤 B를 편집합니다. 최종 룩북은 B를 사용합니다.
7. 디지털 룩북에서 PNG를 저장해 3:2 포토프린터로 출력합니다. **학생 교체 전에 저장합니다.** 사진 포함은 선택 사항입니다. 내려받은 파일은 학생 교체로 삭제되지 않습니다.

## 4인 운영
120분 시간표는 앱의 수업 가이드에서 확인합니다. 개별 결과를 끝까지 연결하려면 한 학생이 한 세션에서 다섯 모듈을 거치고 교체해야 합니다. 모듈별로 네 학생이 번갈아 앉는 경우 중간 카드를 저장하고 색상값을 기록합니다. 초기화한 세션을 복원하는 기능은 없습니다.

## 구현
- index.html, studio.css, studio.js — 실습 화면, 세션과 룩북
- vision.js — MediaPipe Tasks Vision 0.10.21, 정면·크기·가림 범위·좌우 조명 검사, 8프레임 이상 품질 통과 시 측정. 이마와 볼의 작은 패치에서 채널 중앙값을 구하고 최근 프레임의 중앙값을 사용. 세 부위 평균 sRGB를 D65 CIELAB로 변환. 얼굴형 규칙은 화면에서 확인 가능.
- wardrobe.js — 타원 단면 메쉬를 회전·투영하는 Canvas 소프트웨어 3D 렌더러. 옷감 물리 시뮬레이션 없음.
- 모델/런타임만 외부에서 다운로드합니다. 웹캠 영상, 측정값, 선택값은 탭 메모리에 유지합니다. 헤어 실루엣은 2D 도해이며 기존 긴 머리를 지우거나 배경을 복원하지 않습니다.

## 배포
저장소의 main 브랜치 루트에 이 파일들을 놓고 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. 별도 빌드나 서버 키는 필요하지 않습니다.
